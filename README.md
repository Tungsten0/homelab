# HomeLab

Personal homelab environment built around Proxmox VE, Docker, ZFS, networking, monitoring, and infrastructure automation.

## Infrastructure

- Proxmox VE hypervisor
- ZFS mirrored storage
- Debian file server
- Debian Docker host
- Tailscale remote access

## Docker Services

- Uptime Kuma

## Planned Services

- Nextcloud
- Prometheus
- Grafana

## Repository Structure

- `docker/` — Docker Compose services
- `docs/` — infrastructure documentation
- `scripts/` — administration and automation scripts
